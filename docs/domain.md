# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕景区合并拆分后的身份连续性开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

景区主体有身份沿革：合并把多个前身主体并入新主体（或其中一个延续主体），拆分从一个主体拆出独立景区（原主体可延续）。沿革事件以公告、批文为来源依据，按生效日期决定主体存续区间；区间按 [起始, 结束) 解释，生效当日材料归属新主体。

材料归属以观察时点为准：暗访记录、设施评估、等级决定归属到当时有效的主体与评价范围，之后主体合并拆分不回写历史归属。历史查询按查询时点解释名称指向的主体，跨主体证据沿沿革链显式追查，不自动汇总。

新申请引用旧主体材料必须逐项声明继承，注明前身主体、依据事件与评价范围；依据事件被纠正取代后不得再引用。沿革被纠正时，引用受影响身份的待发布决定得到提示并暂停交付，已公开决定保留原引用，纠正影响另行记录并可追踪。
